title: "Give Your AI Agents a Sandbox: Running Untrusted Agent Code Safely on Kubernetes"
speakers:
  - aditya-joshi

AI エージェントが生成・実行する信頼できないコードを、Kubernetes 上で安全に動かす方法を紹介します。Kubernetes SIG プロジェクト「Agent Sandbox」の CRD、gVisor による分離、権限の削減、サービストークンの自動マウント無効化などを解説。ウォームプールから強化された Python サンドボックスを起動し、エージェントが生成したコードを実行・破棄するデモも行う予定です。
